# TryHackMe-tasks-CK

This repository contains completed technical tasks submitted for the **CodeKrafters** club recruitment process.

### Included Tasks

* **Task 1: Networking Fundamentals &amp; Protocols** Covers core networking concepts including IPv4 and MAC addressing, MAC spoofing, ICMP ping diagnostics, traceroute, and WHOIS utilities. It explores the 7-layer OSI reference model, encapsulation/de-encapsulation mechanics, and Protocol Data Units.
* **Task 2: Core Security Concepts Explainer** Examines foundational cybersecurity principles, focusing on the **CIA Triad** (Confidentiality, Integrity, Availability). It breaks down the differences between **Encryption vs. Hashing** and **Authentication vs. Authorization** using real-world scenarios.
